# v1.0.5

修四个「用久了才暴露」的问题，并给它在群里一个「这次可以不说话」的选择。

## 修了什么

- **清空记忆后不再逐条回旧通知**：重置时把当前时间当作跳过水位；旁路重启不再把水位退回 0。
- **群聊后私聊不再没反应**：发送加 20 秒看门狗、内核 30 秒超时、连续两次失败进入冷却，界面上会写明原因。
- **切换会话不再丢聊天记录**：渲染层按会话线缓存历史，拉取失败时回退缓存而不是清空。
- **清理/重置记忆时关系归零**：关系阶段回到陌生人、亲密 0、信任 0.5、七项驱动清零。

## 加了什么

- 私聊/群聊自知：提示词分别写明「只有你们两个人」「群里有别人」。
- 群聊会话可选「自己决定回不回」：模型输出 `<不回>` 就不发，也不留一条假记录。

## 验证

- `npm test` 22 文件 122 用例全绿。
- `npm run smoke:kernel` 96 项全过。
- 安装包 `Anteros-Setup-1.0.5-x64.exe`（Windows x64，未签名）。

## 仍然没做的

- 真实微信里「不回」的行为未在真机上观察过（需要群里有人闲聊）。
- 图片/语音等非文本消息仍只回文本。
