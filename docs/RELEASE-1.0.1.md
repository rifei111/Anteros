# Anteros 1.0.1

这一版只做一件事：**让「微信能不能发出去」变成你能自己点一下验证的事。**

## 新增

- 通道页（设置 → 通道 → 微信）里加了一块「它最近读到的 / 发出的」，还有一行输入框和「发一条测试消息」按钮。
  - 点它，Anteros 会真的通过微信界面把这句话发给你的主对话对象（默认第一个），并把用时和结果告诉你。
  - 下面会列出最近 20 条收发：收到什么、发出什么、失败的带原因。只存在内存里，重开就清空。
- 内核新增 `channels.wechat.sendTest` 与 `channels.wechat.recent` 两个接口（面板用它们，命令行也能用）。

## 实测

- 真机验证：在开着微信 4.1.15 的机器上，用真实数据目录快照起内核 → 通道就绪 → 发一条 → **1.6 秒发出，outbound 计数 +1**，最近列表里有这条记录。
- `npm test`：19 个文件 112 用例全绿；`npm run smoke:kernel`：89 项全过；`package-check`：25 通过 0 警告 0 错误。
- 打包产物面板自检：报告里能读到「发一条测试消息」「它最近读到的 / 发出的」。

## 说明

- 这一版的「发出去了」指的是微信界面真的把消息送出去了；对方是否回你，取决于对方。
- 群聊、图片/语音这类非文本消息仍然只做识别与记录，不会替它回图片。
- 版本号按你的要求收口了：0.12.0 之后不再按提交发版，1.0.x 只修问题、不扩范围。
