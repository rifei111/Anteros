# Anteros v0.11.0

这个版本把「模型」和「人设」从写死变成可配置，顺手修了两个会让人以为软件坏了的 bug。

## 新增

- **多模型**：管理面板新增「多模型」页，可以在聊天框顶部直接选当前对话用哪个模型；也可以按**任务类别**（对话 / 记忆抽取 / 生图 / 语音）分别指定模型与参数。内置 DeepSeek、OpenAI、通义千问、Moonshot、智谱、Ollama、自定义等预设，密钥只存本机。
- **人设文档**：人格页可以把当前人设导出成一份 Markdown 文档（名字、城市、说话习惯、参数表），改完再导入；导入时只覆盖人设内容，记忆和聊天记录不动。

## 修复

- **「表达与完全体」点进去整页白屏，只能重启**：根因是渲染层没有错误边界，任何一个组件抛错都会让整个界面卸载。现在加了一处错误边界，出错时只坏那一块并显示原因与「重试」。顺带给客户端加了单实例锁，避免开两个窗口抢同一个内核。
- **清空记忆后，回复只出现在本机、微信端收不到**：之前内核在通道未就绪时会把出站消息静默丢掉。现在改成不丢——记为失败原因、可见可查；清空记忆后还会主动刷新一次通道状态。

## 已验证

- 类型检查 0 error；vitest 18 个文件 108 用例全绿；内核端到端冒烟 83 项全过（含多模型路由、人设文档往返、通道丢消息回归）。
- 打包产物实跑：管理面板能看到「多模型」页签与「人设文档」区块（生成、导出、从文件读取、导入），引擎版本 0.11.0。

## 仍未验证

- 真实模型的多模型切换（本机没有可用 API Key）；人设文档导入后在真实对话里的风格变化。
- 微信通道的真实收发（需要微信 4.x 桌面版登录 + 便携 Python 运行环境）。

## 安装

下载 `Anteros-Setup-0.11.0-x64.exe` 运行即可；升级会复用 `latest.yml` + blockmap 做增量更新，内核、插件与记忆都存在数据目录，不受升级影响。
