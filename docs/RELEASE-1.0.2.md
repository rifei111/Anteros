## Anteros v1.0.2

修 v1.0.0 里两个"看着成立、其实不成立"的假设。

### 群聊真的能收到了
旁路进程原来只按**一个会话**轮询——界面上把群加进「对话对象」也没用，内核把整张清单传下去了，旁路根本没看。现在按清单逐个会话轮询，各带各的水位，群和私聊同时盯。

### 群里看得出谁在说话
- 每条群消息带发送者昵称与微信号，落库写进 `messages.sender_name / sender_id`。
- 群里按群聊语义排版：你在群里是旁观者，**它的回复在右侧**，其他群成员在左侧带首字头像和昵称。
- 私聊保持原样（你右、它左），不显示昵称。

### 顺手修的两个坑
- 数据库迁移不幂等：库中若已存在 `sender_name` 列（手工修库/迁移中断），启动直接报 `duplicate column name`。现在先查 `PRAGMA table_info` 再加列。
- 全角写法认不出：`＠昵称`、`昵称：正文` 用的是全角符号，原来既不认 @ 也不剥前缀。

### 验证
| 项目 | 结果 |
| --- | --- |
| `npm test` | 21 文件 119 用例全绿（新增群聊气泡 4、迁移 3） |
| `npm run smoke:kernel` | 92 项通过 0 失败（新增会话分线 2 项） |
| `npm run test:sidecar` | 群聊解析 14 项通过 |
| 打包版界面实测 | 群会话 3 条左侧（带昵称/首字头像）+ 1 条它的回复在右侧 |

### 没有验证的部分（不谎报）
真实群消息的收发要微信群里有真人说话才能验。你装好后在群里 @ 它一句，通道页底部「看最近 20 条收发」里有那条、并且它回了一句，就是最终判据。
