# 规范对照

把设计草案与工程规范逐条落到本仓库**实际文件**，并诚实标注状态。

状态定义：

- **已实现**：代码存在，有入口，能按规范工作。
- **部分实现**：主路径在，但边界/异常/测试不完整。
- **进行中**：文件正在写，尚不能完整构建或联调（M0c 前会闭合）。
- **未实现（范围外）**：明确不在 v0.1 范围，已写进 [M0范围.md](M0范围.md)。

> 本表随代码更新；最后核对时间：2026-10-26。
