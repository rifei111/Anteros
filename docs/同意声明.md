# 同意声明

进入 Anteros 前必须逐条阅读并勾选下面九条，**全勾才能进入**。没有"快速同意"、没有默认预勾、
不代勾；任何一条不勾，`accept()` 直接返回 `EINVALID`。

版本：`CONSENT_DOC_VERSION = "2026-10.1"`（`packages/shared/src/version.ts`）。
文案来源：`packages/shared/src/consent.ts` 的 `CONSENT_ITEMS`。UI 与内核读同一份文案，
不存在"界面显示一套、记录另一套"。

### c1 这是一个 AI 拟人智能体

Anteros 是一个由大语言模型驱动的软件程序，它可能说话很像真人，但它不是真人。

### c2 它可能像真人，但不是真人

它的记忆、情绪、日常与关系都是程序模拟出来的，不存在真实的意识、感受或线下身体。

### c3 不能作为事实的唯一来源

它说的话可能有误、可能记错、可能编造细节。请不要把它的输出作为医疗、法律、财务或重大情感决策的唯一依据。

### c4 外部通道会读写你的本机客户端

启用任何外部通道插件（例如微信通道）后，该插件会读取本机客户端的本地数据库、并模拟操作客户端界面来发送消息，
这可能影响你的账号安全，甚至导致账号被限制或封禁。是否启用由你逐项决定，默认关闭。

### c5 不得用于伤害他人

不得使用 Anteros 进行诈骗、骚扰、勒索、冒充他人、骗取财物或其他违法活动。使用者承担全部法律责任。

### c6 不还原、不备份他人撤回的消息

Anteros 不会反制撤回、不会备份他人的已撤回消息。撤回只会被记录为「对方撤回了一条消息」，
正文不落库、不展示、不上传。

### c7 密钥与数据不出本机

外部通道所需的密钥、解密后的数据库内容只在本机使用，不上传云端。调用大模型 API 时只会发送装配后的对话上下文，
不会发送密钥或原始数据库。

### c8 你随时可以停用并清空

你可以随时一键停用所有通道插件、导出或删除本机数据。停用后外部客户端会被还原，不留下自动化痕迹。

### c9 未满 18 岁请勿使用

本软件面向成年人。未满 18 周岁请勿使用。

## 版本化规则

1. 文案**任何改动**（含措辞、条目增删、标点与顺序）都算新版本：必须同时改
   `packages/shared/src/version.ts` 的 `CONSENT_DOC_VERSION`，并在本文件同步。
2. 版本号格式 `YYYY-MM.N`：`2026-10.1` 表示 2026 年 10 月第 1 版；同月再改则 `.2`。
3. 内核只认**当前版本**的勾选记录：`services/consent.ts` 的 `status()` 要求
   `user_consents.doc_version === CONSENT_DOC_VERSION`，否则视为未同意，重新弹闸。
4. 旧版本记录保留在 `user_consents` 里（审计用），但不再生效；不允许"自动沿用旧同意"。
5. 撤回：`revoke()` 后所有需要同意的写操作返回 `ECONSENT`，直到重新逐条勾选。
6. 记录内容：版本、时间、九条各自的勾选值、本机 user id 的哈希；不记录 IP、不联网校验。
7. 文案与代码不同步视为 bug：`consent.ts` 是唯一真源，本文档与 UI 都必须与它一致。
