# Anteros 1.1.1

第一次在这里发安装包。这一版把界面换成了一套「哑光纸」的语言，并修掉换界面时压坏的一处设置页布局。

## 下载

- `Anteros-Setup-1.1.1-x64.exe`（117.7 MB）· Windows 10/11 x64
- 未签名，SmartScreen 会提示「未知发布者」——点「更多信息 → 仍要运行」。
- 数据和程序分开放：程序装到你选的位置，数据在 `%APPDATA%\Anteros\`，卸载不会删数据。

## 界面：哑光纸

不是换配色，是换了一套语言。三条原则写在 `DESIGN.md` 里：

- **一台机器上的一个房间，不是一只微信皮肤。**
- **不伪造。** 没有「正在输入」的三点脉冲、没有假在线、没有假已读。
- **层级靠对比度、字号、留白**，不靠投影和渐变。

具体：

1. 聊天壳重写——侧栏、气泡、输入条、开屏页按同一套令牌重排。它说的话是纸上的字，我说的话是压上去的小卡片；强调色（砖红）一屏只出现一次。
2. 设置面重写——管理面板不再另起一套风格，和聊天区共用控件、字号、圆角；7 档字号，没有第 8 个值。
3. 声明闸、连接页、完全体确认页跟着改；危险操作仍是两段式确认。
4. 深色模式：纸 `#121110`、墨 `#ededef`（17.4:1），强调色 `#c8765c`。
5. 开屏页用应用图标。

## 修掉的一个 bug

新设置面的设置行是「128px 标签 + 控件」两列栅格，而人格页的「人格内核」「表达参数」用的是每格 168px 的小卡片网格——两列栅格套进 168px，控件列只剩 20 多像素，输入框缩成小方块、数字被裁掉看不见。

库里的值一直是好的（4500 / 0.7 / 1 / 3 / 0.04），是布局把控件压没了。现在这两块退回竖排（标签在上、输入框占满整格）；用无头浏览器加载真实构建产物量过：五个输入框 171×34，数字正常。
