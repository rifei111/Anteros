# Anteros 1.1.4

从 1.1.1 到现在，三版改动都在微信通道上：发语音条、搜会话、说话的顺序。
这一版把「发一条字，屏幕上搜一次」这个最碍眼的问题按住了。

## 下载

- `Anteros-Setup-1.1.4-x64.exe`（118.8 MB）· Windows 10/11 x64
- 未签名，SmartScreen 会提示「未知发布者」——点「更多信息 → 仍要运行」。
- 程序装到你选的位置，数据在 `%APPDATA%\Anteros\`，卸载不会删数据。

## 同一个会话连续发，不再反复搜

以前的实现里，每次发送都是一个新进程，"界面上现在开着哪个会话"永远读不到，于是每条消息都老老实实点开搜索框搜一遍；一句回复分四条，眼前就闪过四次搜索。

现在把"刚发到哪个会话"记在本机数据目录里：两分钟内还是同一个会话就直接发，不搜。真去搜的那一次成功后也会记下来。界面读得到当前会话名时以界面为准。

跳过搜索时，发完立刻回读目标会话的最新一条，确认是自己刚发的那句；对不上就报失败、清掉记录——宁可让用户看到「未发送」，也不装作发好了。

## 气泡生成完就发，说话顺序不乱

以前整段回复写完才一起发出去，等的是「全部写完」的时间。现在每写好一条就转出去，体感快很多。

顺序上做了两条约束：第一条语音之后不再抢跑（免得后面的文字抢在语音前面），语音那条始终等合成完成再发，它后面的文字排队等它。

## 微信语音条：真的发得出去，也不撒谎

- 合成一段话发成微信语音条，靠的是虚拟声卡：把语音播进 `CABLE Input`，微信从默认录音设备录走。驱动包随安装包带着，声音页有「下载驱动包」和「一键安装虚拟声卡」，装完自检一次就能用。
- 虚拟声卡没接好时**不会硬发**——回录是静音就直接拦下、退回发文字，并且把界面上那条语音气泡撤掉（以前气泡留着，看着像发出去了、其实没有）。
- 「语音档位选纯文字」现在真的不发声了，外部通道也一样。

## 几处稳定性的修补

- **"正在输入中"一直转**：内核投递循环中途抛错时，收尾的 `stop` 事件被跳过。现在整个循环包在 `try/finally` 里，不管怎么炸都收掉；客户端另外按会话过滤，不让别人的对话在本会话里显示"正在写"。
- **群聊里自己发的话被当成群成员**：群聊视图把"不是它说的"一律摆左边、贴"群成员"。现在先认"这条是不是我发的"，我发的仍在右边、不带昵称。
- 会话切换只在真的需要切换时才发生，界面不再重复跳。

## 数据与边界

- 全部在本机：记忆、人格、聊天记录、密钥都不出这台电脑；审计只记"改了什么"，不记正文。
- 微信通道仍然默认关闭，打开要过风险声明与逐项授权；白名单之外的人不会收到任何消息。
- 语音条一次最多一句（长话拆成几句、每句一条），避免长文本合成崩在中间。

如果你是从 1.1.1 或更早升上来的，装这一版即可；内核数据格式没变，不用重置。
