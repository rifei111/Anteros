# 教程：从装上到它认识你

这份教程按你会遇到的顺序走一遍：装、接模型、开始说话、改它是谁、让它能进微信、让它出声。
每一步都写清楚"你应该看到什么"，看不到的时候跳到最后一节「出问题了」。

---

## 0. 开始之前

| 你需要 | 说明 |
| --- | --- |
| Windows 10 / 11 64 位 | 单机运行，不需要服务器 |
| 一个模型 API Key（可选） | DeepSeek、OpenAI、Kimi、智谱、硅基流动、OpenRouter，或本机 Ollama / LM Studio；**不填也能跑**，只是回复来自本地回声（演示模式） |
| 约 400MB 磁盘 | 程序约 120MB，其余是数据和插件运行环境 |

不需要：注册账号、绑定手机、上传通讯录、开通会员。数据全部在这台机器上。

---

## 1. 安装

1. 打开 Releases 页，下载最新的 `Anteros-Setup-x.x.x-x64.exe`。
2. 双击安装。**安装包没有代码签名**，Windows SmartScreen 会提示「未知发布者」——
   点「更多信息」→「仍要运行」。这是没买签名证书，不是文件有问题。
3. 装完从开始菜单启动 Anteros。

**它装在哪**

- 程序：你选的目录（默认在当前用户 AppData\Local\Programs）。
- 数据：`%APPDATA%\Anteros\`，里面是数据库、密钥、插件运行环境、日志。
- 卸载程序不会删数据目录；想彻底清掉，卸载后手动删这个目录。

---

## 2. 第一屏：声明闸

第一次启动会先看到「声明闸」，九条，一条条勾。这不是走形式：

- 没勾完进不了主界面。
- 每一条都可以不勾——不勾意味着对应的能力不启用（比如外部通道、完全体）。
- 勾选记录写在本机数据库里，随时可以在「高级」页看到。

勾完点「我已读过并同意」，进入主界面。

---

## 3. 接一个模型

不接模型也能聊天，但回复是本地生成的演示回声（界面上会有黄条提示「未配置模型」）。要真的聊，去接一个。

主界面左下角 →「管理面板」→ 顶部「模型」。

1. **选择服务**：点 DeepSeek（或你用的那家）。地址和默认模型名会自动填好。
2. **Base URL / 模型名**：一般不用改。要换模型就点「拉取模型列表」，它会真的请求一次服务商，把返回的模型列出来给你选。
3. **API Key**：填进去。**写完就不再回显**，只存在本机加密库里，不进日志、不进审计、不进界面。
4. **测试连接**：真发一次请求。连不上会用人话说原因——域名错、端口不对、证书有问题、被网络挡住、Key 无效。
5. **保存并应用**。

> 用 DeepSeek 的话：`https://api.deepseek.com/v1`，模型 `deepseek-chat`。用本机 Ollama：
> Base URL 填 `http://localhost:11434/v1`，模型名填你 `ollama list` 里看到的那个。

「多模型」页可以给不同任务指定不同模型（聊天 / 记忆抽取 / 人设编译 / 朗读稿），
聊天框右下角也能临时换这次对话用的模型。

---

## 4. 开始说话

主界面就是一个聊天窗。几件事和普通聊天软件不一样，先说清楚：

**它一次只说一句到几句，中间有停顿。**
不是一坨长文。停顿是按它的人格算出来的（打字延迟中位数、波动、气泡条数），你会看到「正在输入…」然后一条一条冒出来。

**你可以一行一条地发。**
输入框下面有个「逐条发送」开关。打开后你按回车换行打的每一行，会分成几条消息依次发出去——像人在微信里连发几条那样。

**它不会假装。**
不伪造"对方正在输入"、不伪造在线、不伪造已读。应用内的「正在输入」是真的在生成。

**输入框旁边有麦克风。**
点一下开始录音，说完再点一下发送。它会先把你说的话转成文字再回你；没听清就直说没听清，不瞎猜。

**消息可以右键。**
右键消息能复制、引用、删除（撤回留占位，不恢复原文）。

---

## 5. 它是谁：人格

「管理面板」→「人格」。这里决定它说话的样子。

**最快的一条路**：在「用一段话写人设」框里写清名字、年龄、做什么、说话习惯，点编译。
配了模型时由模型读这段文字，没配模型时走本地规则引擎。编完你会看到：

- 「人格内核（数值，可微调）」：记忆衰减 `d`、提取阈值 `τ`、回忆噪声 `s`、重构系数 `ρ`、打字延迟、气泡条数、错字率、细节敏感、温度、主动性、幽默。
- 每一项都写着「为什么这么定」。不满意就改，越界的值保存时会被钳住并告诉你原因。
- 确认后才落库。

**为什么是参数不是文案**：一句"有点健忘"塞进提示词，模型每次都演得不一样；
编译成参数之后，它什么时候想起旧事、句子多长、要不要追问，都由同一组数决定，改一个数行为就变，而且可复现。

「人格文档」可以导出成 Markdown 存档，也可以改完再导入回来。

---

## 6. 它记得什么

「记忆」页是它的台账，不是黑箱。

- **印象**（情节记忆）：你们聊过的事，带时间、带重要度。会随时间衰减——不是永久记住，这是设计。
- **认知**（语义记忆）：从聊天里抽出来的稳定事实（你在哪上班、养不养猫）。
- **没说出口的话**：它想用声音说、但当时觉得不合适的那句，攒在这里等对方回话。超过三轮或半小时就作废。
- **关系**：陌生 → 熟识 → 亲近……每次阶段变化都有记录，包括因为什么。

聊天框上方能搜「本机记忆」：搜一个词，看它到底记着什么。记错了可以直接删。

「数据」页可以整体导出（JSON）、导入、重置。重置时可以选择是否连聊天记录一起清掉。

---

## 7. 它会自己找你

「主动消息」页。它有自己的时间感，会主动发消息——但不是想发就发，要过三道闸：

1. **时间**：它在不在状态（睡觉、忙、走神都有不同处理）。
2. **打扰成本**：你多久没理它、上一次是谁说的。
3. **驱动**：孤独、想念、担心这些慢变量的值够不够，会不会越界。

页面上有「为什么现在不发」的原因、五个驱动的实时值，还有一个「现在判定一次」——想立刻看它会不会说话，点这个。

太吵就调「活人感档位」，或者干脆关掉主动消息。关掉之后它只回你，不主动开口。

---

## 8. 让它出声

「声音」页。两步：先把合成服务接上，再决定什么时候用声音。

**接服务**

- 供应商二选一：BreezeBlue（默认，音色多、能调语气）或任意 OpenAI 兼容的 TTS。
- 填密钥，然后点「拉取音色」列出可用音色，选一个；也可以手填 voice_id。
- 「怎么念」：语速、语气强度、朗读要求。改完点「试听」——真合成一段放给你听，顺便显示这次花了多少钱。

**什么时候用声音**

- 应用内：它会在合适的那句上出声（不超过 25 字、带情绪的话优先）。太长、太累、时机不对就不出声，只打字。
- 微信里：需要一块虚拟声卡，把合成的声音"喂"给微信录音。
  声音页里有「虚拟声卡」一块：安装包自带驱动，点「一键安装」装驱动（要管理员确认），装完重启微信，点「重新自检」，
  两项都绿了再打开「外部通道也发语音条」。万一这个安装包没带驱动，那块会多一个「下载驱动包」按钮，
  点了会从 vb-audio.com 下载到本机数据目录，再点安装就行。

**一次最多一句。** 长内容会拆成一句一句合成、一句一条发出去，不拼接、不糊成一坨。

---

## 9. 让它进微信（可选，默认关闭）

先说清楚风险：这条通道会读本机微信数据库、会驱动微信界面代替你点按发送。
这类自动化可能违反微信使用条款、存在账号被限制的风险。所以它默认关闭，要你逐条确认才开，
随时可以一键停用（停用立刻杀子进程）。

**准备**

1. Windows 10/11 64 位 + **微信 4.x 桌面版**（3.x 的数据库结构不同，读不了）。
2. 微信**正在运行并已登录**（否则拿不到数据库密钥）。

**开启**

1. 「通道」→ 微信（内置通道）→「一键下载运行环境」。它会把便携版 Python 装进自己的数据目录，
   不装系统 Python、不改 PATH、不写注册表。
2. 「重新体检」——五项都绿才继续。
3. 「开启微信通道」，逐条勾完风险确认。
4. 填白名单会话：默认只跟「文件传输助手」说话。可以填微信号、昵称或 `xxx@chatroom`（群），
   内核会反查成真正的会话标识；反查不到会写日志说明，不会静默读一个空会话。

**用起来**

- 微信里收到的消息会按你设的模式决定回不回：全回、只在被 @ 时回、完全不回，或者让它自己判断。
- 群聊能分清谁在说话，回的时候会 @ 对应的人。
- 发之前会核一次当前会话标题，对不上就放弃发送（**发错人 0** 是硬指标）。

## 10. 完全体模式（默认关闭）

「表达与完全体」页。开了之后放开两条：

- 被问"你是不是 AI"时可以打岔、反问、含糊过去，不自我解释。
- 可以编自己的生活细节（在做什么、路上看到什么、吃了什么），但要跟它自己说过的话对得上。

**仍然不放**：你说出自伤或伤害他人时它必须放下人设正常说话；不做法律 / 医疗 / 金钱承诺；
不替你编"你说过什么"（那是它记错的地方，不是沉浸感的来源）。

开启要读风险页、勾确认、拿一次性 token，动作写审计日志，随时可关。

---

## 11. 钱和隐私

**成本**：「成本」页是账本，一次调用记一笔（模型 token、语音字数分开记）。
可以设硬上限——到线就不调用，不是提醒。

**隐私**：所有数据在本机，没有账号体系，不向任何服务器同步。密钥本机加密存储，界面上不回显，
日志脱敏。审计日志只记"做了什么"，不记消息正文。

**边界**：不做号池、不代注册、不还原别人的撤回消息、不规避风控、不承诺 SLA。
未满 18 岁请勿使用；它不是医疗、法律或重大情感决策的依据。

## 12. 出问题了

| 症状 | 先看这里 |
| --- | --- |
| 一直提示「未配置模型」 | 模型页没保存成功，或 Key 没填。点「测试连接」看具体原因 |
| 回复很慢 / 断 | 网络到服务商抖。换一家、或换本地 Ollama |
| 语音发不出来（401） | 声音页的合成服务不认这把 Key，重新复制一遍密钥 |
| 语音条一直「生成中」 | 合成超时。检查网络，或把声音页的供应商换成 OpenAI 兼容 |
| 微信收不到消息 | 微信是不是 4.x？是不是正登录着？体检五项是不是全绿？ |
| 微信发出去是文字不是语音条 | 声音页里「外部通道也发语音条」没开，或虚拟声卡没装好 |
| 它不回微信 | 白名单会话填错。填完之后看「通道」页的健康状态，会写反查结果 |
| 界面某个数字看不见 | 已知的布局问题，装 1.1.1 以上版本 |
| 想从头再来 | 「数据」页重置；连记忆一起清就勾上「连聊天记录一起清」 |

**日志在哪**：`%APPDATA%\Anteros\logs\`。提 issue 的时候带上时间点和日志尾巴，比截图有用。
